# prompt-template

Claude Code 입력창 바로 위에 단계별 프롬프트 템플릿을 띄우는 mod입니다.
칸을 하나씩 채우고 Enter로 넘기면, 마지막에 완성된 프롬프트가 입력창에 채워집니다.

## 설치

터미널 세션의 프롬프트에서:

```
/plugin install prompt-template --marketplace nasaro-pro/claude-prompt-template
```

셸에서:

```
claude plugin install prompt-template --marketplace nasaro-pro/claude-prompt-template
```

데스크톱 앱에서는 입력창 옆 **+ → Plugins → Add marketplace**에 `nasaro-pro/claude-prompt-template`를 넣고, **Add plugin**으로 설치합니다.

마켓플레이스 추가를 묻는 질문에 `y`, 범위는 user를 고르면 이후 모든 세션에서 동작합니다.

## 사용법

- 새 대화를 열면 입력창 위에 템플릿이 펼쳐져 있습니다. 안 보이면 `/pt` 또는 `/template`.
- **Enter**: 다음 칸 (비워 두면 `없음`) · 마지막 칸에서는 입력창에 채움
- **버튼칸**: ←/→로 고르고 Enter, 또는 숫자키
- **↑**: 위에 쌓인 작성 항목으로 이동 → Enter로 그 칸 수정 → Enter로 쓰던 칸에 복귀
- 도구 줄: 템플릿 목록(새 템플릿 만들기 포함) · 새로 · 편집 · 이전 · 접기
- 편집 화면: 칸 추가(글칸/버튼칸), 버튼칸 선택지(쉼표 구분), 템플릿 삭제, 보낸 기록

## 참고

- Claude Code의 mod(함수 훅) 기능은 얼리 액세스입니다. Claude Code 2.1.311에서 테스트했습니다.
- 템플릿·보낸 기록은 각자의 컴퓨터에 저장되고, 작성 중인 내용은 대화마다 따로 남습니다.
- 모바일과 데스크톱 앱의 일반 채팅(Chat 탭)에서는 동작하지 않습니다.
- 테스트: `claude plugin test <이 폴더>`
